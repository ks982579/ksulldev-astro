You may end up needing to use [PowerShell](https://learn.microsoft.com/en-us/powershell/scripting/overview?view=powershell-7.5)
at some point in your career, so learning some scripting now isn't a bad idea.
PowerShell profiles are configuration files that run when you start a PowerShell session,
like the bashrc file for bash.
They are perfect for setting up aliases, function, and other customizations on Windows.
PowerShell has a few different profiles, some combination like:

```PowerShell
$PROFILE.AllUsersAllHosts
$PROFILE.AllUsersCurrentHost
$PROFILE.CurrentUserAllHosts
$PROFILE.CurrentUserCurrentHost
```

The "Hosts" refers to the console in use, the "CurrentHost" means only the PowerShell console.
`$PROFILE` on its own defaults to the current-current profile.
Check if you have a profile, and create one if you don't:

```PowerShell
Test-Path $PROFILE
# false
New-Item -ItemType File - Path $PROFILE -Force
```

Now, I don't believe Windows has a built-in text editor, so use `notepad $PROFILE` or `code`.
You can then add things like:

```PowerShell
Set-Alias ll Get-ChildItem
Set-Alias pwd Get-Location

$env:PATH += ";$env:USERPROFILE\.local\bin"

function touch {
  param([string[]]$Path)

  foreach ($file in $Path) {
    if (Test-Path $file) {
      (Get-Item $file).LastWriteTime = Get-Date
    } else {
      New-Item -ItemType File -Path $file -Force | Out-Null
    }
  }
}
```

In the above, I've recreated the bash `touch` command as an example.
The `-Force` flag creates parent directories if they don't exist.
And the `Out-Null` suppresses the output from `New-Item`.

If you type `$env` you can tab through to learn some new things, like there's a `$env:DEVELOPER_DIR`.
Use the `&` operator when calling executables with variables to ensure PowerShell treats the string as an executable path.
And now, the best for last:

```PowerShell
# Global variable for your scripts directory
$env:PYTHON_SCRIPTS_PATH = "$env:USERPROFILE\python_scripts"

function work-helper {
    param(
        [Parameter(Mandatory=$true)]
        [string]$Action,
        [Parameter(ValueFromRemainingArguments=$true)]
        [string[]]$AdditionalArgs
    )

    # Map actions to script files
    $scriptMap = @{
        '-new-day'  = 'new_day.py'
        '-new-task' = 'new_task.py'
    }

    # Check if action is valid
    if (-not $scriptMap.ContainsKey($Action)) {
        Write-Host "Invalid action. Available actions: $($scriptMap.Keys -join ', ')" -ForegroundColor Red
        return
    }

    $scriptName = $scriptMap[$Action]
    $scriptPath = Join-Path $env:PYTHON_SCRIPTS_PATH $scriptName
    $venvPath = Join-Path $env:PYTHON_SCRIPTS_PATH "venv"
    $activateScript = Join-Path $venvPath "Scripts\Activate.ps1"

    # Check if files exist
    if (-not (Test-Path $scriptPath)) {
        Write-Host "Script not found: $scriptPath" -ForegroundColor Red
        return
    }

    if (-not (Test-Path $activateScript)) {
        Write-Host "Virtual environment not found: $activateScript" -ForegroundColor Red
        return
    }

    try {
        # Activate virtual environment
        & $activateScript

        # Run the Python script with additional arguments
        python $scriptPath @AdditionalArgs
    }
    finally {
        # Deactivate virtual environment
        if (Get-Command deactivate -ErrorAction SilentlyContinue) {
            deactivate
        }
    }
}
```

This fun script with active and deactivate python virtual environments, and run Python scripts for you.
Python is a simple scripting language that's also cross platform.
Now any scripts you put in your "python_scripts" directory can be called in powershell!

Using `grep` in PowerShell has always been a small issue as well.
In the console you can run:

```PowerShell
Get-ChildItem . -Recurse | Select-String "phrase to find"
```

Or you can...

```PowerShell
function grep {
    param([string]$Pattern, [string]$Path = ".")
    Get-ChildItem $Path -Recurse -File | Select-String $Pattern |
        ForEach-Object { "$(Resolve-Path $_.Filename -Relative):$($_.LineNumber):$($_.Line.Trim())" }
}
```
